# Cassie's Typing Game

This is my first project using Next.js and React to make a responsive fun game for me to learn about the framework.

---

## About

- I wanted to keep a retro theme going on so i use a dark theme with B&W and red accents.
- To play you just type and the input bar reads the current word compared with the word you need to type in the top and highlights the appropriate letters.
- Added a sidebar to try a sliding effect and to have color and word customization.
- Finally when you complete the words there is confetti!
